# Marka işaretleri

Yalnızca giriş butonlarında, sağlayıcıların marka kurallarına uygun (renk değiştirmeden, yanında metinle) kullanılır.

| Dosya | Kaynak |
|---|---|
| `google-g.svg` | Google "Sign in with Google" standart renkli G — https://developers.google.com/identity/branding-guidelines |
| `facebook.svg` | Meta marka kaynakları (#0866FF) — https://about.meta.com/brand/resources/facebook/logo — çizim Simple Icons (CC0) üzerinden |
| `apple.svg` | Apple logosu — https://developer.apple.com/design/human-interface-guidelines/sign-in-with-apple — çizim Simple Icons (CC0) üzerinden |

Sağlayıcıların resmi indirme paketleri gelirse bu dosyaların yerine konabilir.
