# Ödeme markaları

Ödeme adımında kabul edilen yöntemleri göstermek için. Renkler ve oranlar değiştirilmez.

| Dosya | Kaynak |
|---|---|
| `visa.svg`, `mastercard.svg`, `amex.svg`, `apple-pay.svg`, `google-pay.svg` | [gilbarbara/logos](https://github.com/gilbarbara/logos) (`@iconify-json/logos`, CC0) |
| `ideal.svg` | [CoreUI Brands](https://github.com/coreui/coreui-icons) (`@iconify-json/cib`, CC0), iDEAL markası rengi #CC0066 |

Markaların hakları sahiplerine aittir. Mollie bağlanınca Mollie'nin ödeme yöntemi logoları
(Methods API `image.svg`) ya da markaların resmi dosyaları bunların yerine konmalı; iDEAL'in
iDEAL | Wero'ya geçişi de oradan takip edilir.
